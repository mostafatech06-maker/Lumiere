# LUMIÈRE

This is a sleek, modern fine dining restaurant website built purely with HTML and CSS. No heavy frameworks or complicated JavaScript just clean code, smooth styling, and a polished visual layout designed to bring a high-end restaurant experience to life online. i only used AI to solve code errors, and the usage does not exceed 30%.

## Features
### Hero Section
An inviting landing page featuring clear call-to-action buttons that push visitors toward reserving a table or checking out the menu.

### Our Story (About Section)
A dedicated area spotlighting the culinary vision behind Lumière, complete with key stats like years of experience, signature dish counts, Michelin stars, and overall guest satisfaction.

### Interactive Menu
A organized view of the restaurant's signature offerings, categorized into appetizers, main courses, desserts, and drinks, all complete with pricing.

### Visual Gallery
A high-res photo grid showcasing the restaurant’s cozy ambiance and artfully plated dishes.

### Table Reservations
A clean, easy-to-use booking form where guests can select dates, times, party sizes, and drop in special requests.

### Newsletter Signup
A quick form allowing guests to subscribe for seasonal menu drops, exclusive events, and private tasting invites.

### Location & Footer
Everything guests need to get in touch or visit in person, including operating hours, location details, and social media links.
